GridLAB-D project subcommand

SYNOPSIS

Shell:

    $ gridlabd project [OPTIONS ...] COMMAND [ARGUMENTS ...]

GLM:

    #project [OPTIONS ...] COMMAND [ARGUMENTS ...]

DESCRIPTION

    The `gridlabd project` command manages GridLAB-D projects in GitHub.
    GridLAB-D projects can be opened from GitHub repositories and edited
    using Marimo.

    To use the `gridlabd project` command you must first login to GitHub 
    using the `gh auth login` command.

OPTIONS

    -d|--debug               Enable debug output and exception traceback
    -h|--help|help           Display this help information
    -o|--org ORG             Specify the GitHub ORG
    -q|--quiet               Disable error output
    -v|--verbose             Enable verbose output
    -w|--warning             Disable warning output

COMMANDS

    config
      show                   Show the current configuration
      set KEY=VALUE[,...]    Change configuration setting
    create PROJECT           Create and open a new project
    edit PROJECT             Edit an existing project in Marimo
    list [WORKDIR]           List projects in WORKDIR (. by default)
    open PROJECT             Open an existing project on GitHub
    save MESSAGE             Save project to github

CONFIGURATION

    The following keys and values are supported by the `config` command:
    
    branch=BRANCH

        Determines the default branch name to use when creating new
        repositories.

    debug=None

        The `debug` value enables exception traceback during processing.

    exception=False

        The `exception` value enables raising exceptions instead of displaying
        error messages and returning error codes.

    gitorg=ORG

        Determines the default GitHub organization or user in which new
        repositories are created.

    quiet=False

        The `quiet` value suppresses error messages during processing.

    template=arras-energy/.project

        The `template` value specifies the GitHub project template to use when
        creating a new project.
        
    verbose=False

        The `verbose` value enables verbose message output during processing.

    warning=True

        The `warning` value enable warning messages during processing.

    workdir=$HOME/Projects

        The `workdir` value specifies the default working folder for projects.
        You can override this by specifying the full path to the project.
